# Доклады по статической маршрутизации

Материалы для курса «Моя первая научная статья». Презентации рассчитаны на формат 16:9 и собраны по актуальной версии статьи.

| Файл | Содержание |
|---|---|
| [o-slide.pdf](o-slide.pdf) | Один слайд для выступления до минуты |
| [m-talk.pdf](m-talk.pdf) | Промежуточный доклад из десяти слайдов, ориентир 4:30 |
| [speaker-notes.md](speaker-notes.md) | Текст выступлений, ориентиры по времени и ответы на вопросы |
| [o-slide.tex](o-slide.tex), [m-talk.tex](m-talk.tex), [common.tex](common.tex) | Редактируемые исходники LaTeX Beamer |

## Сборка

Понадобятся XeLaTeX, latexmk и пакеты Beamer, TikZ, Polyglossia и CM Unicode.

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error o-slide.tex m-talk.tex
```

## Откуда взяты данные

Слайды 6–10 используют таблицы 1–6 статьи «Компиляция статической маршрутизации с нелинейностью до агрегации». Результаты сравнения архитектур относятся к выбранным по валидации чекпойнтам. На слайде 7 приведены три сопоставимые серии при ранге 8. На слайдах о компиляции база ускорения — точный кеш той же маршрутизирующей модели. Ссылки на близкие работы встроены в третий слайд M-talk.
