# Компиляция статической маршрутизации с нелинейностью до агрегации

Автор — [SadWork](https://github.com/SadWork).

В скрытом слое каждый нейрон усредняет отклики BiReLU по обученному статическому распределению маршрутов. Компилятор сохраняет наиболее вероятные маршруты и массы остальных входов по группам. Общие префиксные статистики позволяют вычислять вклад каждой группы при индивидуальном пороге нейрона.

На CIFAR-10 скомпилированный классификатор при обработке одного изображения на Apple M3 Pro работал в 2,81 раза быстрее точного кеша той же сети и требовал в 10,3 раза меньше памяти для массивов и явных рабочих буферов. Средняя потеря тестовой точности по трём запускам составила 0,35 п.п. на CIFAR-10, 0,14 п.п. на Fashion-MNIST и 0,27 п.п. на CIFAR-100. Оптимизированный Dense FP32 показал меньшую задержку на том же процессоре.
